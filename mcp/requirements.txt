# Task Cards MCP Server requirements
#
# Core (card tools + code-graph tools): the server imports FastMCP from
# `mcp.server.fastmcp`.
mcp>=1.0,<2

# Core (graph web UI): mcp/db_tools/app.py imports flask and dotenv at module
# level and serves the code graph and task cards — not just the optional SQL
# Server subsystem. The MCP server spawns this app on startup, so without these
# the graph UI silently crashes on import and never binds its port.
flask           # mcp/db_tools/app.py graph viewer
python-dotenv   # app.py reads per-repo .env via dotenv_values()

# Pydantic v2 is a DIRECT dependency of the contracts/ package (the Phase 0
# typed contract models + JSON-Schema generation). It currently also arrives
# transitively via `mcp`, but contracts/ imports it directly, so declare it
# explicitly. Permissive pin: any pydantic v2.
pydantic>=2,<3  # contracts/ typed contract models

# Optional extras live in their own files so this core set stays minimal (mcp,
# flask, python-dotenv) and the installers can select them:
#   - database-graph tools (db_* / SQL Server schema graph):  mcp/db_requirements.txt
#     (pyodbc, networkx, pyvis)
#   - central memory (memory_* tools):                        mcp/memory_requirements.txt
# The plugin installers (installer/install.sh, installer/install.ps1) prompt for
# these or accept --with-db / --with-memory (see WINDOWS.md Section 5.4).
